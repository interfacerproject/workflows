# Interfacer reusable workflows

Shared GitHub Actions workflows for the Interfacer project.

- [Publish to GHCR](.github/workflows/publish-ghcr.yml)
- [Node staging deployment](.github/workflows/node-staging-deploy.yml)

Refer to each workflow's `workflow_call` definition for its inputs and required secrets.
